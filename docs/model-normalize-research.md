## Что такое нормализация вектора

Нормализация — приведение вектора к некоторому «стандартному виду».
В контексте ML/эмбеддингов наиболее распространена **L2-нормализация**:
каждый компонент делится на длину (Euclidean norm) вектора.

Формула:
  ||v|| = sqrt(v1² + v2² + ... + vn²)
  v_normalized[i] = v[i] / ||v||

Результат: вектор той же направленности, но длиной 1 (unit vector).

## Альтернативы

| Тип | Формула | Когда применяется |
|-----|---------|-------------------|
| L2 (Euclidean) | v / sqrt(sum(v²)) | ML, embeddings, cosine similarity |
| L1 (Manhattan) | v / sum(\|v\|) | Разреженные данные, robust statistics |
| Min-Max | (x - min) / (max - min) | Приведение к [0, 1], нейросети |

## Решение

Выбираем **L2-нормализацию** — стандарт для ML-задач, к которым относится ModelWorker
(согласно description: "vector normalization / cosine similarity / threshold classification").

## Сигнатура

В этом репозитории используется существующая сигнатура:

    std::vector<double> ModelWorker::normalize(const std::vector<double>& values) const;

Ошибки (пустой вектор, нулевой вектор) выражаются через `std::invalid_argument` —
так же, как в `cosine()` (см. PR #19), чтобы стиль обработки ошибок был единым.

**Альтернативы, которые рассмотрели:**
- Возвращать пустой вектор при ошибке — не подходит: пустой результат неотличим
  от валидного edge-case и молча маскирует ошибку вызывающего.
- `Result normalize(...)` как в форке — в основном репозитории у ModelWorker
  нет такого контракта, переход на `Result` — отдельное архитектурное решение.

## Валидация

Некорректные случаи:
1. **Пустой вектор** — нечего нормализовать. `invalid_argument("Vector must not be empty")`.
2. **Нулевой вектор** — длина 0, деление на ноль. `invalid_argument("Cannot normalize zero vector")`.
3. **Невалидные числа** — обрабатываются на этапе парсинга входных данных.
